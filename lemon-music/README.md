# 柠檬音乐（Lemon Music）

面向飞牛 NAS、Docker 与自托管的 Web 音乐工具，在浏览器内完成「找歌 → 试听 → 下载 → 整理」全流程。

## 功能

- **搜索 / 下载**：兼容落雪 LX Music 自定义音源脚本，支持 FLAC · Hi-Res · 母带品质与批量下载
- **本地音乐库**：库管理、标签编辑、按歌手整理、重复文件清理、伪 FLAC 检测
- **每日推荐**：本地 + 平台混搭推荐、推荐歌单、漫游播放
- **播放体验**：全屏播放、逐字歌词、频谱与风格配色、睡眠定时
- **投屏**：DLNA 投屏与音箱兼容，投屏后本机暂停、切歌自动推送
- **备份恢复**：配置与数据备份

## 环境要求

| 项目 | 要求 |
| --- | --- |
| 系统 | fnOS 1.1.8 及以上 |
| 依赖应用 | 应用中心 Node.js v22 |
| 架构 | x86 / arm |
| 默认端口 | 7983（有系统证书时自动 HTTPS） |

## 安装

通过 fnOS 应用中心手动安装 FPK（本源内下载，按设备架构选择 x86 / arm 包）。
首次登录账号 `admin` / `admin123`，登录后请立即修改密码。
卸载时可选择保留配置目录。
