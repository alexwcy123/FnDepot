# 飞牛影视在线扩展（fnmedia-ext）

飞牛影视第三方在线资源扩展：零侵入、完全可逆地接管官方影视入口，在不修改官方二进制、nginx 与数据库的前提下，为飞牛影视增加在线播放能力。

## 功能

- **原生搜索聚合**：在官方影视的搜索中聚合苹果 CMS 资源站在线片源，搜索结果默认在线前排
- **豆瓣榜单四库**：热门电影 / 热门剧集 / 动漫新番 / 热门综艺（数据来自豆瓣周榜与标签推荐）
- **资源站海量分类四库**：电影 / 剧集 / 动漫 / 综艺，每库约 5000 部，虚拟列表无限滚动、点开即播
- **多线路播放**：m3u8 / mp4 代理播放、多线路切换、噪音过滤
- **播放记录与智能续播**：网页与飞牛影视 App 通用
- **自定义独立媒体库**：管理页可将任意资源站单独生成一张片库卡片
- **TVBox 配置导入**：支持导入 TVBox / 影视仓 / OK影视 订阅配置（base64、多订阅聚合）
- **应用内管理页**：榜单开关、刷新间隔、数据源状态一览

## 环境要求

| 项目 | 要求 |
| --- | --- |
| 系统 | fnOS 1.2.0 及以上 |
| 依赖应用 | 官方「影视 (trim.media)」需保持安装并启用 |
| 架构 | all（纯 Python，安装时创建独立 venv） |

## 安装

通过 fnOS 应用中心手动安装 FPK（本源内下载），安装后启用「飞牛影视在线扩展」即可。
停用扩展会立即将 `/var/run/trim_media.sock` 还原给官方影视服务，完全可逆。
